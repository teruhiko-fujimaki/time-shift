# タイムシフト再生 (Time Shift Camera)

カメラの映像を設定した秒数だけ遅らせて再生するWebアプリケーションです。
自分の動きを少し遅れて確認できるため、スポーツのフォームチェック（ゴルフのスイング、野球の投球など）や、背中の身だしなみ確認などに便利です。

## 特徴

*   **遅延再生機能**: 5秒から15秒の間で、映像を遅らせて表示（タイムシフト）します。
*   **カメラ切り替え**: インカメラとアウトカメラをボタン一つで切り替え可能です。
*   **ミラー（鏡）モード**: インカメラ使用時は、自動的に鏡のように左右反転して表示されます。
*   **レイアウト変更**: 操作ボタンの配置を「右」または「下」に切り替え可能。スマートフォンやタブレット、PCなどデバイスに合わせて使いやすい配置を選べます。
*   **インストール不要**: HTMLファイル一つで動作する軽量設計です。

## 使い方

1.  `index.html` をWebブラウザで開きます（またはGitHub Pages等で公開したURLにアクセスします）。
2.  **「さかのぼる時間」**のスライダーを動かして、遅延させる秒数（5〜15秒）を設定します。
3.  **「スタート！」**ボタンを押します。
    *   ブラウザからカメラの使用許可を求められた場合は「許可」を選択してください。
4.  過去の映像は再生されません。現在の映像のみ再生されます。
5.  終了または設定を変更する場合は**「やりなおす」**ボタンを押してください。

## 動作環境

*   Google Chrome
*   Safari (iOS/macOS)
*   Microsoft Edge
*   その他、MediaRecorder APIに対応したモダンブラウザ

## インストール / デプロイ

このリポジトリの `index.html` をダウンロードしてブラウザで開くだけで動作します。
GitHub Pagesなどの静的ホスティングサービスにアップロードして公開することも可能です。

※ PWAとして使用する場合は、別途 `manifest.json` とアイコン画像を用意してください。
